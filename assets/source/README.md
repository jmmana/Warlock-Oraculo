# assets/source

Material de partida (semillas de estilo, referencias, prototipos heredados) para `tools/asset-forge/` y para quien dibuje/ajuste prompts. **No es arte final.** Nada de aquí se empaqueta en un atlas del producto sin pasar por el ciclo `reference → vector-study → prototype → approved` de `ADR-014`.

- `characters/ceo/` — ficha de referencia aprobada, 6 poses estáticas y el único ciclo de caminar real (prototipo) que existe hoy, portados desde Agent Viewer.
- `characters/other-archetypes/` — un frame estático por rol (Analyst, Developer, Finance, Planner, Reviewer), mismo punto de partida que tenía Agent Viewer.
- `furniture/`, `electronics/`, `effects/` — ~41 SVG de mobiliario y utilería, portados desde una rama no mergeada de Agent Viewer.

Procedencia completa, commits de origen y advertencias heredadas: [`../licenses/source-agent-viewer-2026-10-11.md`](../licenses/source-agent-viewer-2026-10-11.md). Léelo antes de usar cualquier archivo de esta carpeta como si fuera definitivo.
